# 🔢 NumPy Complete Revision & Hands-on Notes

Welcome to my **NumPy Revision Repository**! 🚀  
This repository contains structured, beginner-to-friendly notes, code implementations, and practical examples covering core concepts of **Numerical Python (NumPy)** across 13 structured parts using Jupyter Notebook.

---

## 📚 Topics Covered

1. **Anaconda & First Program** - Environment setup, Conda, and Jupyter introduction.
2. **Creating NumPy Arrays** - `np.array`, `zeros`, `ones`, `empty`, `random`, `arange`, `linspace`, and `identity`.
3. **Array Properties & Attributes** - Inspecting `.shape`, `.ndim`, `.size`, `.itemsize`, `.dtype`, and type conversion with `.astype()`.
4. **Lists Vs Arrays** - Performance, speed, and memory comparison.
5. **Indexing, Slicing and Iteration** - Accessing elements, range slicing, and traversal.
6. **Numpy Array Operations** - Basic arithmetic, unary operations (`min`, `max`, `sum`), and universal functions (`exp`, `sqrt`, `sin`).
7. **Reshaping Numpy Array** - Flattening (`ravel`), reshaping, transposing, stacking, and splitting.
8. **Fancy Indexing** - Selecting elements using index lists for both rows and columns.
9. **Indexing using Boolean Array** - Conditional filtering and masking.
10. **Broadcasting** - Automatic shape stretching for operations on different-sized arrays.
11. **Additional Advanced Concepts** - Extra practice and utility functions.
12. **Data Manipulation & Performance** - Optimized operations and vectorization.
13. **Comprehensive Review & Hands-on Projects** - Final revision notebook combining all concepts.
